# Exercice

Dans ce repo, vous trouverez les deux exercices complétés. 

## Exercice 2 

Vous trouverez à l'intérieur un README avec l'ensemble des réponses aux questions émis dans le livrable. 

De plus, tout les schémas des diagrammes ont été placé dans le dossier diagram. 

L'application n'étant pas donné, est une application minimal d'une API REST en Java en utilisant les contraintes explicite d'où l'utilisation de SQLite. 

Aucun test unitaire n'a été effectué sur ce projet m'étant concentré d'avantage sur l'exercice suivant. 

## Exercice 3

Comme pour l'exercice précédent, vous retrouverez l'ensemble des explications de l'architectures et des choix dans le fichier README. 

Pour l'application, celui-ci a été fait en JavaScript et seulement le minimal a été implément comme notifié dans les notices. Les choix qui ont été fait sont également précisé dans le README dans la partie des Limites.

Une partie des diagrammes ont été fait sur drawio, et le restant (diagramme de séquence et d'activité) sur Plantext.
